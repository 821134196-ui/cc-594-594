# 公交卡挂失补卡与余额转移系统

乘客丢卡后由客服核验身份并补卡：系统**先停用旧卡**，**等待在途消费清算**后计算可转余额，
再把剩余余额**等额转入新卡**；乘客页面可查全程办理进度，客服可追到每笔扣款及转移依据。
闸机、制卡服务、清算中心均为本地模拟。

- **后端**：Java 21 · Quarkus 3.15 · Hibernate ORM (Panache) · SQLite
- **前端**：Svelte 5 + Vite（构建后由 Quarkus 同源提供，单端口 8080）
- **存储**：SQLite 单文件 `backend/data/transit.db`

## 一条命令启动

```bash
./start.sh            # 自动引导 JDK21/Maven/Node（缺失时下载到 .tools），构建并启动
./start.sh --reset    # 清空演示库，恢复三张种子卡后启动
./start.sh --dev      # 后端 8080 + 前端 Vite 热更新 5173（/api 代理）
```

打开 <http://localhost:8080>，页面三个标签：

| 标签 | 内容 |
|---|---|
| **乘客进度** | 新旧卡并列、脱敏流水、余额转移状态、等待清算/已转入提示、办理时间轴 |
| **客服办理** | 身份核验挂失、停用旧卡、制新卡、转账、重试追扣，可逐笔核对扣款与配对流水 |
| **场景演示台** | 闸机刷卡、清算回执上报（含重复/晚到）、充值、故障注入、一键重置 |

自动演示脚本（需要系统已启动）：

```bash
./scripts/demo.sh
```

## 核心业务规则（与实现的对应）

1. **旧卡先停用**：挂失受理（SHA-256 证件号核验）后旧卡立即 `LOST`，闸机对 `LOST/REPLACED`
   卡一律拒绝并把 `GATE_REJECTED` 写入案件进度。
2. **在途消费不立即扣款**：闸机只写 `PENDING` 流水、不动余额；
   `可转余额 = 已清算余额 − 在途预留`，清算回执到达后才 `PENDING→SETTLED` 并扣减余额。
3. **旧卡原流水永不修改**：晚到交易（转账后才清算）保留独立原 `FARE` 流水（含原始乘车时间），
   旧卡加一笔 `LATE_OFFSET(+)` 挂平使余额不漂，差额登记 `LateAdjustment` 并从新卡
   `LATE_CLAWBACK(−)` 追回；新卡余额不足或新卡再次挂失时挂 `PENDING_CLAWBACK`，记录不丢。
4. **一张旧卡只关联一张有效新卡**：进行中案件存在时重复挂失/制卡被 409 拒绝。
5. **重复清算回执不多转钱**：`receiptNo` 唯一登记，重放返回 `DUPLICATE` 与首次结果，
   不结算任何流水；行级 `eventKey` 亦幂等。
6. **转出 = 转入**：`TRANSFER_OUT` 与 `TRANSFER_IN` 在同一事务按同一金额成对写入并互链，
   页面实时校验 `transferredOutCents == transferredInCents`，且卡余额恒等于该卡已清算流水之和。
7. **失败不丢**：制卡/转账失败（演示台可注入故障）落 `FAILED` 案件 + 失败尝试记录，
   资金分毫不动；重新发起沿用原案件与全部历史。新卡再次挂失时，晚到差额沿
   「旧卡→新卡→当前持卡」补卡链追到当前可用卡。

## 页面如何说明资金阶段

- 顶部横幅按案件状态显示：`旧卡已停用` / **`余额仍在等待清算`** / `可转余额已确定` /
  **`余额已转入新卡`** / `办理失败（记录保留）`。
- 两张卡片并列展示：左侧旧卡（灰/停用，显示已清算余额与在途预留），右侧新卡（显示当前可用余额）。
- 对账面板列出：受理快照、在途预留、旧卡累计转出、新卡累计转入、一致性勾稽、
  转移尝试（失败也展示）、晚到差额（原流水#/挂平#/追扣#三向配对）、清算回执（含重复标记）。

## 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/gate/swipe` | 闸机刷卡（旧卡拒绝 / 正常卡登记在途消费） |
| POST | `/api/cases/report-loss` | 客服核验身份并挂失停用旧卡 |
| POST | `/api/cases/{no}/issue-new-card` | 制发新卡（失败返回 `ok:false` 且记录留痕） |
| POST | `/api/cases/{no}/transfer` | 清算完成后等额转账（失败留痕，可重试） |
| POST | `/api/clearing/receipt` | 清算回执（`receiptNo` 幂等，支持晚到离线消费行） |
| POST | `/api/cases/{no}/retry-clawback` | 重试挂账差额追扣 |
| POST | `/api/cards/{cardNo}/recharge` | 充值 |
| GET | `/api/cases/{no}` | 案件聚合视图（新旧卡流水/转移/差额/回执/时间轴） |
| POST | `/api/demo/reset` | 重置种子数据 |
